# Sistema Bancário Simples
Esse é um trabalho da disciplina de Boas Práticas de Programação (DIM0501) ministrada pelo professor Gibeon Soares. 

**Objetivo:** simular um sistema bancário simples para controle de clientes, contas e operações financeiras.

- Liriel Antonia de Lima Felix

## Descrição
O Sistema Bancário Simples permite o cadastro de clientes e contas, além da execução de operações bancárias básicas. Ele foi estruturado para demonstrar o uso de boas práticas de programação, mantendo clareza, legibilidade e responsabilidade única em cada classe.

**Funcionalidades implementadas:**
- Cadastro de clientes e contas.
- Depósito, saque e transferência entre contas.
- Aplicação de rendimento em contas poupança.
- Consulta de saldo individual.
- Listagem de contas em ordem decrescente de saldo, exibindo tipo, número, cliente e saldo atual.
- Geração de relatório consolidado com total por tipo de conta e saldo geral.

## Como compilar e executar o sistema
```
cd src
javac Main.java 
java Main
```
